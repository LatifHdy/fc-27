AUTO-UPDATE GITHUB PAGES

Sinkronisasi GitHub

Dengan menghubungkan Personal Access Token (PAT) GitHub, setiap kali Anda klik SIMPAN HASIL atau NEXT SEASON, JavaScript di browser akan langsung meng-commit dan update file liga.json di repository GitHub secara otomatis tanpa perlu edit manual atau git push!

🔒 Token Anda disimpan aman hanya di localStorage browser Anda sendiri. Pengunjung publik tidak memiliki akses ke token ini.
Buat token di: GitHub > Settings > Developer Settings > Personal access tokens (beri izin centang: repo).

PANDUAN AKTIVASI FIREBASE (CUMA 3 MENIT) Gratis selamanya dari Google
  1. Buka console.firebase.google.com dan login dengan akun Google Anda.
  2. Klik Add Project (beri nama misal fc27-liga).
  3. Di menu kiri, pilih Build > Realtime Database > klik Create Database (pilih lokasi Singapura/US).
  4. Pada tab Rules, ubah menjadi: 
    { "rules": { ".read": true, ".write": true } }
    lalu klik Publish.
  5. Klik ikon Gear ⚙️ (Project settings) > di bagian Your apps pilih Web (</>).
  6. Salin nilai konfigurasi tersebut ke dalam file firebase-config.js di project ini. Selesai!
